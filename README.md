## Data Process packages

The data process was used to process the data generate from the "Q" qcr machine. The data from the machine is stored in a csv file formate with the general naming convension of "4WJ_HEX_{test-type}_{plate number}_{trigger}_{trigger}". There are slight variation of the naming convention depending on the test-type.

### Test type present

There are currently three test types present: concentration (Conc), ratio (Ratio), and screening (screen)

- The concentration test is used to study how the trigger concentration affects the release profile.
- The ratio test is used to study how different ratio of triggers affects the release profile.
- The screening test is used to study how the trigger design affects the release profile.
